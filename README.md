Atualização do Projeto

Nesta versão, concluímos a dinâmica imersiva em laboratório com foco em aprendizado ágil. A atividade envolveu a integração com API e a criação de uma roleta interativa, permitindo que aplicássemos na prática conceitos importantes de programação.

Tecnologias e Técnicas Aprendidas

Integração com API: Aprendemos a consumir dados de APIs usando fetch, para tornar o sistema mais dinâmico e conectado com fontes externas.

Async/Await: Utilizamos async e await para tornar o código mais eficiente, permitindo a execução de tarefas assíncronas sem bloquear o fluxo principal da aplicação.

Try...Catch: Implementamos o tratamento de erros com try...catch para garantir maior segurança e estabilidade no código.
